   - 문의 내용과 답변은 캡처해 보관하세요.

5. **택배사에 직접 문의**
   - 배송 상태가 며칠째 변하지 않거나 배송 완료 처리 오류가 의심되면 택배사 고객센터에 확인합니다.

   - 쇼핑몰의 배송 지연·미배송 신고, 주문 취소 또는 환불 절차를 이용합니다.

**주의:** 판매자나 택배사를 사칭한 문자 링크는 누르지 말고, 배송 조회는 공식 앱·홈페이지에서 직접 확인하는 것이 안전합니다.
