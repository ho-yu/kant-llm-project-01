# 추가 비교 1 — 베이스 모델 vs 파인튜닝 모델 (F vs G)

> **추가 비교 1.** 발제문의 선택 심화 실습(3번째 로컬 모델 비교, Quantization 비교,
> Transformers 직접 실행, Sentence Transformers 임베딩)과는 **별개로**, STEP 8 완료
> 이후 궁금증에서 시작해 추가로 진행한 테스트다. 필수 완료 기준·평가표에는 포함되지
> 않으며, 여기 결과는 이미 확정된 Model F 선정을 바꾸지 않는다.

## 질문 — 도메인 파인튜닝이 실제로 효과가 있는가?

Model F(`sam-1-base`)는 **Qwen2.5-7B-Instruct 에 LoRA 로 이커머스 특화를 얹은 모델**이다.
그런데 F의 모델 카드는 English only 를 명시하는데도 실측 한국어 표현 점수가 4.15 로
가장 높았다 ([step03.md](steps/step03.md)). 이게 파인튜닝 덕인지, 베이스 모델 자체의
능력인지는 지금까지 구분하지 못했다.

**그래서 F의 베이스 모델 자체(Model G)를 똑같은 조건으로 돌려 비교한다.**

## 비교 조건

| | F (기존, 파인튜닝) | G (신규, 베이스) |
|---|---|---|
| 모델 | sam-1-base | Qwen2.5-7B-Instruct |
| 관계 | Qwen2.5-7B-Instruct + LoRA(이커머스 특화) | **그 베이스 자체, 파인튜닝 없음** |
| 모델 태그 | `hf.co/mradermacher/sam-1-base-GGUF:Q4_K_M` | `qwen2.5:7b-instruct` (Ollama 공식 라이브러리) |
| Quantization | Q4_K_M | Q4_K_M (동일) |
| 파라미터 | 7.62B | 7.62B (동일) |
| 질문·조건 | 동일 10문항, temperature=0, num_ctx=4096, 2회 | 동일 |

F와 다른 변수는 **"LoRA 파인튜닝 유무" 하나만** 남도록 통제했다. `models.json` 에
`model_label: "G"`, `tier: "supplementary"` 로 이미 등록해 뒀다 — 채점·최종 선정
대상(`primary`)에는 들어가지 않고, 성능 측정만 `step06.md` '부가 테스트' 표에
자동으로 함께 나온다.

## 실행 방법

```bash
cd project1-python-start

# 1. 모델 다운로드 (Ollama 공식 라이브러리 태그)
ollama pull qwen2.5:7b-instruct

# 2. 환경 정보 갱신 (digest·다운로드 크기 등을 자동 채움)
uv run python -m evalkit.collect_env

# 3. 10_run.py 의 MODEL 을 "G" 로 바꾸고 LIMIT = None 확인 후 실행
uv run python 10_run.py

# 4. 검사·집계 (G 는 부가 테스트 표에 자동 반영됨)
uv run python 11_finish.py
```

> **태그 변경 이력** — 처음엔 `hf.co/bartowski/Qwen2.5-7B-Instruct-GGUF:Q4_K_M` 로
> 등록했으나 실제로는 Ollama 공식 라이브러리의 `qwen2.5:7b-instruct` 를 받았다.
> `ollama show` 로 확인한 결과 Q4_K_M · 7.6B · Apache-2.0 으로 동일해 그대로 채택했다.
> 태그 불일치로 실패했던 21건(워밍업 1 + 본실험 20)은 `data/raw/local/runs.jsonl` 에서
> 제거했다 — 잘못된 모델을 가리켜 호출 자체가 성립하지 않은 오류 기록이라 제거 근거는
> [step06.md](steps/step06.md) '기록 삭제 예외' 와 같은 성격이다.

`10_run.py` 실행 후 **응답 원문**은 `data/raw/local/runs.jsonl` 에 `model_label: "G"`
로 쌓인다. 채점용으로 보기 편하게 뽑으려면 STEP 6 방식과 동일하게
`aggregator.trace("G_Q01_r1")` 로 개별 회차를 확인하거나, 기존 `responses/Q01~Q10.md`
와 같은 형식으로 보고 싶으면 알려주면 만들어 준다.
