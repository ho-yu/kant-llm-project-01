### 원본 기록에 반드시 들어갈 필드

> JSON / CSV / JSONL 등 **다시 읽을 수 있는 형식**으로 저장한다.
> 비교표의 모든 수치는 이 기록에서 나와야 하고, 역추적이 가능해야 한다.

| 필드 | 설명 |
|---|---|
| `run_id` | 실행 ID |
| `question_id` | Q01~Q10 |
| `model` | 모델 태그 (양자화 포함 전체 식별값) |
| `repeat` | 반복 회차 (1 / 2) |
| `is_warmup` | 워밍업 여부 — true면 본 실험 집계에서 제외 |
| `prompt` | 실제 입력 전문 |
| `response` | 원본 응답 전문 |
| `status` | 성공 / 오류 |
| `error` | 오류 내용 (실패 시) |
| `latency_total_s` | 전체 응답 시간 |
| `load_duration_s` | 모델 로딩 시간 |
| `output_tokens` | 출력 토큰 수 |
| `tokens_per_s` | 생성 속도 |
| `vram_mb` | VRAM 사용량 |
| `options` | temperature / num_predict / num_ctx 등 실행 설정 |
| `timestamp` | 실행 시각 |

### 집계 시 반드시 표시할 것 (평가표 #5·#6)

- [ ] 모델별 **호출 성공 수 / 전체 시도 수** (예: 19/20)
- [ ] 지표별 **집계 응답 수(n)** — 평균만 적지 말 것
- [ ] 측정 불가 항목이 있으면 **사유** 기재
- [ ] 워밍업 / 재시도 / 추가 실험은 본 실험 120회와 **분리 집계**
- [ ] **실패**(호출 오류)와 **측정 누락**(호출은 성공했으나 값 없음)을 구분
