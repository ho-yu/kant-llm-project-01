1. 모델 요구사항 정의

2. 선정 기준

(1) 필수 통과 조건

- 한국어 Chat/QA가 가능한 모델일 것
- Ollama에서 실행 가능할 것
- 현재 PC 환경에서 안정적으로 실행 가능할 것
- 상업적 활용에 문제가 없는 License일 것
- 일반적인 이커머스 질의를 처리할 수 있는 Context Length를 가질 것
- STEP 5에서 정의한 최소 품질 기준을 통과할 것



(2) 선호 우선순위

1순위: 답변 품질

3순위: Instruction Following
4순위: 응답 속도
5순위: 메모리 사용량
