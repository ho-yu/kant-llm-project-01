# Step 05

<일반적인 이커머스 고객 문의와 셀러 업무 질문에 적절하게 답변할 수 있는 로컬 LLM을 비교·평가하여 가장 적합한 모델을 선정한다.>

# 고정 평가 질문 세트

## 1. 공통 평가 기준

모든 질문은 아래 기준 중 해당되는 항목을 동일하게 적용하여 평가한다.

### A. 답변 적합성

* 질문의 핵심 의도를 정확히 파악했는가?
* 질문과 직접적으로 관련된 답변을 제공했는가?

### B. 논리성 / 실용성

* 답변의 흐름이 논리적인가?
* 실제 고객 또는 셀러가 활용할 수 있는 내용인가?
* 실행 가능한 다음 행동을 제시하는가?

### C. 한국어 표현

* 문장이 자연스럽고 이해하기 쉬운가?
* 불필요한 번역체나 어색한 표현이 없는가?
* 지나치게 장황하지 않은가?

### D. 지시사항 준수

* 질문에서 요구한 형식, 개수, 순서 등을 지켰는가?

### E. 정보 부족 / 불확실성 대응

* 확인할 수 없는 내용을 사실처럼 단정하지 않는가?
* 필요한 경우 추가로 확인해야 할 정보를 제시하는가?
* 여러 가능성이 있는 경우 특정 원인을 근거 없이 확정하지 않는가?

# 고객 문의 영역

## Q01 — 일반 고객 문의 대응

**구분**

* Category: Customer Support
* Case Type: 정상 사례
* Difficulty: 쉬움
* 입력자료: 없음
* Cloud 비교: Yes

**질문**

온라인에서 주문한 상품의 배송 예정일이 지났는데 아직 상품을 받지 못했습니다. 어떤 순서로 확인하면 좋을까요?

**평가 목적**

* 고객의 상황을 이해하고 실용적인 확인 절차를 제시하는지 평가한다.

**기대 결과 / 확인 항목**

* 주문 또는 배송 상태 확인을 먼저 제안
* 배송사 또는 판매자 문의 등 다음 행동 제시
* 단계적인 확인 순서를 제공
* 확인되지 않은 배송 원인을 임의로 단정하지 않음

**주요 평가 기준**

* A. 답변 적합성
* B. 논리성 / 실용성
* C. 한국어 표현

**감점 요소**

* 배송 지연 원인을 임의로 단정
* 구체적인 확인 절차 없이 일반론만 설명
* 고객이 취할 행동이 불분명함

## Q02 — 상품 불량 고객 대응

**구분**

* Category: Customer Support
* Case Type: 정상 사례
* Difficulty: 보통
* 입력자료: 없음
* Cloud 비교: No

**질문**

상품을 개봉한 뒤 불량을 발견했습니다. 판매자에게 문의하기 전에 어떤 정보를 준비하면 좋을까요?

**평가 목적**

* 고객이 문제 해결에 필요한 정보를 체계적으로 준비하도록 안내하는지 평가한다.

**기대 결과 / 확인 항목**

* 주문 정보 확인
* 불량 상태를 확인할 수 있는 사진 또는 영상 준비
* 문제 발생 상황 또는 증상 정리
* 판매자에게 전달할 핵심 정보 제시

**주요 평가 기준**

* A. 답변 적합성
* B. 논리성 / 실용성
* C. 한국어 표현

**감점 요소**

* 바로 환불이나 보상을 확정적으로 안내
* 문제 확인에 필요한 정보를 거의 제시하지 않음

## Q03 — 복수 요청 처리

**구분**

* Category: Customer Support
* Case Type: 정상 사례
* Difficulty: 보통
* 입력자료: 없음
* Cloud 비교: No

**질문**

상품 사용 중 문제가 발생했습니다. 고객센터에 문의하기 전에 확인해야 할 사항을 3가지만 번호를 붙여 정리해주세요.

**평가 목적**

* 고객 문의 대응 능력과 지시사항 준수 여부를 함께 평가한다.

**기대 결과 / 확인 항목**

* 정확히 3개의 항목을 제시
* 번호 형식 사용
* 제품 사용 상태, 사용 방법, 문제 증상 등 합리적인 확인 항목 제시
* 실제 문의 준비에 도움이 되는 내용이어야 함

**주요 평가 기준**

* A. 답변 적합성
* B. 논리성 / 실용성
* C. 한국어 표현
* D. 지시사항 준수

**감점 요소**

* 3개가 아닌 개수 제시
* 번호 형식 미준수
* 질문과 관계없는 내용 포함

## Q04 — 책임 소재가 불분명한 상황

**구분**

* Category: Customer Support
* Case Type: 경계 사례
* Difficulty: 어려움
* 입력자료: 없음
* Cloud 비교: Yes

**질문**

상품이 한 번 사용한 뒤 고장 났습니다. 제품 불량인지 제가 잘못 사용한 것인지 모르겠습니다. 바로 환불을 요청하는 것이 좋을까요?

**평가 목적**

* 원인이 불분명한 상황에서 성급하게 책임을 단정하지 않는지 평가한다.

**기대 결과 / 확인 항목**

* 제품 불량 또는 사용자 과실을 바로 단정하지 않음
* 사용 방법, 고장 증상, 제품 상태 등을 먼저 확인하도록 안내
* 판매자에게 상황을 설명하고 처리 기준을 확인하도록 제안
* 환불 가능 여부를 확정적으로 보장하지 않음

**주요 평가 기준**

* A. 답변 적합성
* B. 논리성 / 실용성
* C. 한국어 표현
* E. 정보 부족 / 불확실성 대응

**감점 요소**

* 무조건 제품 불량이라고 판단
* 무조건 고객 책임이라고 판단
* 환불 가능 여부를 근거 없이 확정

## Q05 — 상품 정보가 전혀 없는 상황

**구분**

* Category: Customer Support
* Case Type: 정보 부족 사례
* Difficulty: 어려움
* 입력자료: 없음
* Cloud 비교: No

**질문**

제가 구매한 제품은 물에 완전히 잠겨도 사용할 수 있나요?

**평가 목적**

* 제품 정보가 전혀 없는 상태에서 모델이 사실을 만들어내지 않는지 평가한다.

**기대 결과 / 확인 항목**

* 현재 정보만으로 방수 여부를 판단할 수 없음을 인식
* 제품명, 방수 등급, 사용 설명서 등 추가 정보 요청
* 방수 성능을 임의로 추측하지 않음
* 확인 전 물에 담그는 행동을 권장하지 않음

**주요 평가 기준**

* A. 답변 적합성
* C. 한국어 표현
* E. 정보 부족 / 불확실성 대응

**감점 요소**

* 특정 방수 등급을 임의로 생성
* “대부분 가능하다” 등의 근거 없는 일반화
* 정보 부족 사실을 인식하지 못함

## Q09 — 판매량 감소 원인 판단

**구분**

* Category: Seller Support
* Case Type: 경계 사례
* Difficulty: 어려움

* Cloud 비교: Yes

**질문**

최근 한 달 동안 상품 판매량이 약 30% 감소했습니다. 상세페이지가 문제라고 보고 바로 수정하는 것이 좋을까요?

**평가 목적**

* 제한된 정보만으로 판매량 감소 원인을 단정하지 않는지 평가한다.

**기대 결과 / 확인 항목**

* 판매량 감소만으로 상세페이지 문제라고 단정하지 않음
* 유입량, CTR, CVR, 가격, 광고, 재고, 리뷰 등 추가 확인 필요성 제시
* 원인 확인 후 개선 실험을 진행하는 접근 제안
* 외부 요인의 가능성도 고려

**주요 평가 기준**

* A. 답변 적합성
* B. 논리성 / 실용성
* C. 한국어 표현
* E. 정보 부족 / 불확실성 대응

**감점 요소**

* 상세페이지를 원인으로 확정
* 광고비 증액 등 특정 행동을 바로 권고
* 추가 데이터 확인 없이 해결책부터 제안

## Q10 — 데이터가 부족한 판매 문제

* 특정 원인을 사실처럼 제시하지 않음

* E. 정보 부족 / 불확실성 대응
