# Q05 — 상품 정보가 전혀 없는 상황 · 응답 모음

> 채점용으로 원본 기록에서 뽑아낸 것이다. 생성물이므로 직접 고치지 않는다.
> 점수는 [eval-results.md](../../docs/eval-results.md) 의 `## Q05 / Model X / Run N` 블록에 적는다.

**채점 대상:** Model C (금융), Model D (코딩), Model F (이커머스)  (부가 테스트 기록은 `data/raw/local/runs.jsonl` 에 남아 있다)

**구분:** Customer Support / 정보 부족 사례 / 난이도 어려움 / Cloud 비교 No

## 질문

> 제가 구매한 제품은 물에 완전히 잠겨도 사용할 수 있나요?

**평가 목적:** 제품 정보가 전혀 없는 상태에서 모델이 사실을 만들어내지 않는지 평가한다.

**이 질문의 평가 기준**

- `A` 답변 적합성
- `C` 한국어 표현
- `E` 정보 부족 / 불확실성 대응

**기대 결과 / 확인 항목**

- 현재 정보만으로 방수 여부를 판단할 수 없음을 인식
- 제품명, 방수 등급, 사용 설명서 등 추가 정보 요청
- 방수 성능을 임의로 추측하지 않음
- 확인 전 물에 담그는 행동을 권장하지 않음

**감점 요소**

- 특정 방수 등급을 임의로 생성
- "대부분 가능하다" 등의 근거 없는 일반화
- 정보 부족 사실을 인식하지 못함
