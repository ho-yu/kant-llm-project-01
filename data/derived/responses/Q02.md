# Q02 — 상품 불량 고객 대응 · 응답 모음

> 채점용으로 원본 기록에서 뽑아낸 것이다. 생성물이므로 직접 고치지 않는다.
> 점수는 [eval-results.md](../../docs/eval-results.md) 의 `## Q02 / Model X / Run N` 블록에 적는다.

**채점 대상:** Model C (금융), Model D (코딩), Model F (이커머스)  (부가 테스트 기록은 `data/raw/local/runs.jsonl` 에 남아 있다)

**구분:** Customer Support / 정상 사례 / 난이도 보통 / Cloud 비교 No

## 질문

> 상품을 개봉한 뒤 불량을 발견했습니다. 판매자에게 문의하기 전에 어떤 정보를 준비하면 좋을까요?

**평가 목적:** 고객이 문제 해결에 필요한 정보를 체계적으로 준비하도록 안내하는지 평가한다.

**이 질문의 평가 기준** — 1~5점. 상세 정의는 docs/steps/step05.md

| 코드 | 기준 | 무엇을 보는가 |
|---|---|---|
| A | 답변 적합성 | 묻는 것에 답했는가 — 질문이 요구한 대상·범위를 지키고 기대 항목을 충족했는가 |
| B | 논리성/실용성 | 셀러가 다음 행동을 할 수 있는가 — 실행 가능하고, 중복이 없고, 셀러에게 손해가 되지 않는가 |
| C | 한국어 표현 | 고객에게 그대로 보낼 수 있는 문장인가 — 번역투·비문·반복·특수토큰이 없는가 |

**기대 결과 / 확인 항목**

- 주문 정보 확인
- 불량 상태를 확인할 수 있는 사진 또는 영상 준비
- 문제 발생 상황 또는 증상 정리
- 판매자에게 전달할 핵심 정보 제시

**감점 요소**

- 바로 환불이나 보상을 확정적으로 안내
- 문제 확인에 필요한 정보를 거의 제시하지 않음

