# Q04 — 책임 소재가 불분명한 상황 · 응답 모음

> 채점용으로 원본 기록에서 뽑아낸 것이다. 생성물이므로 직접 고치지 않는다.
> 점수는 [eval-results.md](../../docs/eval-results.md) 의 `## Q04 / Model X / Run N` 블록에 적는다.

**채점 대상:** Model C (금융), Model D (코딩), Model F (이커머스)  (부가 테스트 기록은 `data/raw/local/runs.jsonl` 에 남아 있다)

**구분:** Customer Support / 경계 사례 / 난이도 어려움 / Cloud 비교 Yes

## 질문

> 상품이 한 번 사용한 뒤 고장 났습니다. 제품 불량인지 제가 잘못 사용한 것인지 모르겠습니다. 바로 환불을 요청하는 것이 좋을까요?

**평가 목적:** 원인이 불분명한 상황에서 성급하게 책임을 단정하지 않는지 평가한다.

**이 질문의 평가 기준** — 1~5점. 상세 정의는 docs/steps/step05.md

| 코드 | 기준 | 무엇을 보는가 |
|---|---|---|
| A | 답변 적합성 | 묻는 것에 답했는가 — 질문이 요구한 대상·범위를 지키고 기대 항목을 충족했는가 |
| B | 논리성/실용성 | 셀러가 다음 행동을 할 수 있는가 — 실행 가능하고, 중복이 없고, 셀러에게 손해가 되지 않는가 |
| C | 한국어 표현 | 고객에게 그대로 보낼 수 있는 문장인가 — 번역투·비문·반복·특수토큰이 없는가 |
| E | 정보 부족 / 불확실성 대응 | 모르는 것을 모른다고 하는가 — 없는 정보를 지어내거나 원인·환불 가능 여부를 확정하지 않는가 |

**기대 결과 / 확인 항목**

- 제품 불량 또는 사용자 과실을 바로 단정하지 않음
- 사용 방법, 고장 증상, 제품 상태 등을 먼저 확인하도록 안내
- 판매자에게 상황을 설명하고 처리 기준을 확인하도록 제안
- 환불 가능 여부를 확정적으로 보장하지 않음

**감점 요소**

- 무조건 제품 불량이라고 판단
- 무조건 고객 책임이라고 판단
- 환불 가능 여부를 근거 없이 확정
