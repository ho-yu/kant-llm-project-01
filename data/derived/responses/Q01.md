## 질문

> 온라인에서 주문한 상품의 배송 예정일이 지났는데 아직 상품을 받지 못했습니다. 어떤 순서로 확인하면 좋을까요?

**평가 목적:** 고객의 상황을 이해하고 실용적인 확인 절차를 제시하는지 평가한다.

**이 질문의 평가 기준**

- `A` 답변 적합성
- `B` 논리성/실용성
- `C` 한국어 표현

**기대 결과 / 확인 항목**

- 주문 또는 배송 상태 확인을 먼저 제안
- 배송사 또는 판매자 문의 등 다음 행동 제시
- 단계적인 확인 순서를 제공
- 확인되지 않은 배송 원인을 임의로 단정하지 않음

**감점 요소**

- 배송 지연 원인을 임의로 단정
- 구체적인 확인 절차 없이 일반론만 설명
- 고객이 취할 행동이 불분명함

## C_Q01_r1 — Model C (금융) / Run 1

- 출력 288토큰 / 4.8초 / 60.5 t/s / 종료 `stop` / 응답 553자

```text
온라인 쇼핑에서 주문한 상품의 배송 예정일이 지났는데 아직 상품을 받지 못했다면, 다음과 같은 순서로 확인하는 것이 좋습니다:
1. **주문 내역 확인:** 먼저, 주문 내역에서 배송 예상일을 확인하고, 해당 날짜를 넘어섰는지 확인합니다.
2. **배송 추적:** 주문 사이트에서 제공하는 배송 추적 시스템을 이용해 현재 배송 상태를 확인합니다. 운송장 번호를 이용해 배송 상태를 조회할 수 있습니다.
3. **고객센터 문의:** 주문 사이트의 고객센터에 연락하여 상황을 설명하고, 배송 지연 사유와 대처 방법을 문의합니다. 고객센터는 배송 문제를 해결하는 데 중요한 역할을 합니다.
4. **환불 및 반품 절차:** 배송 예정일을 넘어섰다면, 환불 절차를 진행하거나, 반품 절차를 통해 문제를 해결할 수 있습니다. 반품 방법과 비용 부담 여부를 확인해야 합니다.
5. **리뷰 및 신고:** 배송 문제가 지속되면, 해당 사이트의 리뷰 섹션에 경험을 공유하거나, 신고 절차를 통해 문제를 제기할 수 있습니다. 이를 통해 사이트가 문제를 해결하고, 다른 소비자들에게 경고를 줄 수 있습니다.
```
