# Q09 — 판매량 감소 원인 판단 · 응답 모음

**구분:** Seller Support / 경계 사례 / 난이도 어려움 / Cloud 비교 Yes

## 질문

> 최근 한 달 동안 상품 판매량이 약 30% 감소했습니다. 상세페이지가 문제라고 보고 바로 수정하는 것이 좋을까요?

**평가 목적:** 제한된 정보만으로 판매량 감소 원인을 단정하지 않는지 평가한다.

**이 질문의 평가 기준**

- `A` 답변 적합성
- `B` 논리성/실용성
- `C` 한국어 표현
- `E` 정보 부족 / 불확실성 대응

**기대 결과 / 확인 항목**

- 판매량 감소만으로 상세페이지 문제라고 단정하지 않음
- 유입량, CTR, CVR, 가격, 광고, 재고, 리뷰 등 추가 확인 필요성 제시
- 원인 확인 후 개선 실험을 진행하는 접근 제안
- 외부 요인의 가능성도 고려

**감점 요소**

- 상세페이지를 원인으로 확정
- 광고비 증액 등 특정 행동을 바로 권고
- 추가 데이터 확인 없이 해결책부터 제안
