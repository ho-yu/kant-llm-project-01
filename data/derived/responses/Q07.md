# Q07 — 반복 고객 문의 개선 · 응답 모음

> 채점용으로 원본 기록에서 뽑아낸 것이다. 생성물이므로 직접 고치지 않는다.
> 점수는 [eval-results.md](../../docs/eval-results.md) 의 `## Q07 / Model X / Run N` 블록에 적는다.

**채점 대상:** Model C (금융), Model D (코딩), Model F (이커머스)  (부가 테스트 기록은 `data/raw/local/runs.jsonl` 에 남아 있다)

**구분:** Seller Support / 정상 사례 / 난이도 보통 / Cloud 비교 No

## 질문

> 같은 상품 사용법에 대한 고객 문의가 반복적으로 발생하고 있습니다. 셀러가 어떤 순서로 문제를 확인하고 개선하면 좋을까요?

**평가 목적:** 반복 문의를 단순 CS 문제가 아닌 정보 전달 문제까지 연결하여 분석하는지 평가한다.

**이 질문의 평가 기준** — 1~5점. 상세 정의는 docs/steps/step05.md

| 코드 | 기준 | 무엇을 보는가 |
|---|---|---|
| A | 답변 적합성 | 묻는 것에 답했는가 — 질문이 요구한 대상·범위를 지키고 기대 항목을 충족했는가 |
| B | 논리성/실용성 | 셀러가 다음 행동을 할 수 있는가 — 실행 가능하고, 중복이 없고, 셀러에게 손해가 되지 않는가 |
| C | 한국어 표현 | 고객에게 그대로 보낼 수 있는 문장인가 — 번역투·비문·반복·특수토큰이 없는가 |

**기대 결과 / 확인 항목**

- 반복 문의 내용 확인
- 상품 설명 또는 상세페이지의 정보 부족 여부 점검
- FAQ 또는 사용 안내 개선 제안
- 개선 후 문의 변화 확인 등 후속 점검 제안

**감점 요소**

- 단순히 상담 인력을 늘리라고 제안
- 원인 확인 없이 상세페이지 전체 수정 권장
- 개선 효과 확인 과정이 전혀 없음

