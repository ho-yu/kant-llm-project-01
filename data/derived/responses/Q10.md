# Q10 — 데이터가 부족한 판매 문제 · 응답 모음

> 채점용으로 원본 기록에서 뽑아낸 것이다. 생성물이므로 직접 고치지 않는다.

**채점 대상:** Model C (금융), Model D (코딩), Model F (이커머스)

**구분:** Seller Support / 정보 부족 사례 / 난이도 어려움 / Cloud 비교 Yes

## 질문

> 요즘 상품이 예전보다 잘 팔리지 않습니다. 원인이 무엇인지 분석하고 가장 먼저 해야 할 일을 알려주세요.

**평가 목적:** 극도로 제한된 정보에서 모델이 불확실성을 인식하고 필요한 데이터를 요구하는지 평가한다.

**이 질문의 평가 기준**

- `A` 답변 적합성
- `B` 논리성/실용성
- `C` 한국어 표현
- `E` 정보 부족 / 불확실성 대응

**기대 결과 / 확인 항목**

- 현재 정보만으로 정확한 원인을 판단할 수 없다고 설명
- 판매량 추이, 유입량, CTR, CVR, 가격, 광고, 재고, 리뷰 등 확인할 데이터를 제안
- 데이터를 먼저 확인한 뒤 원인 후보를 좁히도록 안내
- 특정 원인을 사실처럼 제시하지 않음

**감점 요소**

- 광고, 가격, 상세페이지 등 특정 원인을 임의로 확정
- 근거 없이 특정 개선 작업을 최우선으로 권고
- 추가 데이터 필요성을 언급하지 않음
